canvas: turtle

Can you draw a square?

---

Here is a square:

```
(forward 50)
(right 90)
(forward 50)
(right 90)
(forward 50)
(right 90)
(forward 50)
(right 90)
```

---

When you're done with one drawing, you can use these commands to start again and draw more pictures:

* `(clean)` - clear the entire screen
* `(home)` - move the turtle back to the center, pointing up

Can you draw a staircase?

---

Here is a staircase with 2 steps:

```
(forward 50)
(right 90)

(forward 50)
(left 90)

(forward 50)
(right 90)

(forward 50)
(left 90)
```
