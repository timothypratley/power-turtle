உங்களுக்கு ஒரு சதுரத்தை வரையமுடியுமா?

---

இதோ ஒரு சதுரம்:

```
(முன்னால் 50)
(வலது 90)
(முன்னால் 50)
(வலது 90)
(முன்னால் 50)
(வலது 90)
(முன்னால் 50)
(வலது 90)
```

---

Use these commands to draw more pictures:

* `(துப்புரவு)` - முழு திரையின் உள்ளடக்கத்தைத் துப்புரவு செய்வது
* `(வீடு)` - ஆமையை நடுவுக்குக் கொண்டுவந்து மேலே நோக்க வைப்பது

---

2 படிகளைக் கொண்ட படிக்கட்டு இது:

```
(முன்னால் 50)
(வலது 90)

(முன்னால் 50)
(இடது 90)

(முன்னால் 50)
(வலது 90)

(முன்னால் 50)
(இடது 90)
```

உங்களுக்கு என்ன வரைய முடியும்?

இவற்றை வரைந்து பாருங்கள்:

- ஒரு முக்கோணம்
- ஒரு கூட்டல் குறி
- சில தமிழ் எழுத்துகள்: ட, ப, டா, பா, பு
- சில ஆங்கில எழுத்துகள்: L, T, V, W, X, N
- asterisk குறி "*", hash குறி "#"
