'V' என்ற எழுத்தை வரைய பின்னால் போய் மறுபக்கத்துக்கு திரும்பி மீண்டும் முன்னால் போகவேண்டும்.

மறுபக்கத்துக்கு திரும்பவதற்கு திரும்பும் அளவு இரண்டும் மடங்கு அதிகமாகத் திரும்பவேண்டும்.
முதல் அளவு முதல் திசையை நோக்க வைக்கும்.
இரண்டாவது அளவு அங்கிருந்து மறுபக்கத்துக்குத் திரும்பவது.

What if did the same thing, but only turned 45 degrees?


We get half an octagon. If we do it again, we will finish the whole octagon.

```
(முன்னால் 50)
(வலது 45)
(முன்னால் 50)
(வலது 45)
(முன்னால் 50)
(வலது 45)
(முன்னால் 50)
(வலது 45)
```

---

It is difficult to repeat the commands many times.
We can repeat a set of commands N times by putting them inside `(repeat N #(do  ... ))`

```
(துப்புரவு)
(வீடு)
(repeat 8 #(do (முன்னால் 50) (வலது 45) ))
```

---

We don't have to write each command on a single line. We only need to ensure that the parenthases are equal.

```
(துப்புரவு)
(வீடு)
(repeat 8 #(do
            (முன்னால் 50)
            (வலது 45)))
```
